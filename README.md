# ZeroTrace

ZeroTrace — быстрая, легковесная и бескомпромиссная утилита для Windows, объединяющая продвинутый деинсталлятор программ с глубокой очисткой системы, менеджер автозагрузки и сервис мгновенного поиска файлов.

Нативное приложение на базе WPF / .NET Framework без использования тяжелых веб-движков. Размер исполняемого файла составляет всего ~370 КБ.

---

## Возможности

### 1. Деинсталлятор программ (Uninstaller)
- **Стандартное удаление**: запуск штатного деинсталлятора приложения с последующим глубоким сканированием и удалением всех оставшихся файлов, папок и веток реестра.
- **Принудительное удаление (Force Removal)**: быстрое завершение активных процессов программы и полное стирание всех связанных следов на диске и в реестре (подходит для поврежденных или вредоносных программ без рабочего деинсталлятора).
- **Пакетное удаление**: выбор нескольких программ для последовательной деинсталляции и очистки в один клик.
- **Быстрые действия**: переход к папке установки, открытие записи в `regedit`, поиск сведений в Google, скрытие устаревших записей из реестра.
- **Поддержка Win32 и UWP**: обнаружение классических программ Windows и приложений Microsoft Store.

### 2. Менеджер автозагрузки (Autoruns)
- **Комплексный аудит системы**: сканирование разделов реестра Run/RunOnce, папок автозагрузки, планировщика задач (Task Scheduler), системных служб и драйверов, контекстного меню Проводника, кодеков и подсистем.
- **Управление состоянием**: включение и отключение автозапуска с поддержкой формата Sysinternals и диспетчера задач Windows.
- **Безопасность**: проверка цифровых подписей (Authenticode), фильтрация доверенных компонентов Microsoft и быстрый анализ подозрительных файлов на VirusTotal по SHA-256.

### 3. Мгновенный поиск (Everything & NTFS USN Engine)
- **Собственный движок NTFS USN**: прямое чтение журнала изменений NTFS без предварительной индексации за доли секунды.
- **Интеграция с Everything**: автоматическое подключение через IPC, если служба Everything уже запущена в системе.
- **Действия с найденными элементами**: открытие в Проводнике, копирование путей, отправка в Корзину или безвозвратное удаление.

### 4. Интерфейс и удобство
- **Темная тема**: минималистичный дизайн с темным нативным заголовком окна (DwmSetWindowAttribute).
- **Двуязычность**: мгновенное переключение между русским и английским языками интерфейса (`RU` / `EN`) без перезапуска.
- **Плавная прокрутка**: встроенная физика сглаживания колеса мыши для удобной навигации по большим спискам.

## Сборка из исходников

### Требования
- Windows 10 / 11 (x64)
- .NET Framework 4.5 или новее
- MSBuild (входит в состав .NET Framework или Visual Studio Build Tools)

### Команда сборки
```cmd
%SystemRoot%\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe ZeroTrace.csproj /p:Configuration=Release /p:Platform=x64
```

Собранный исполняемый файл будет доступен в каталоге:
```
bin\Release\ZeroTrace.exe
```

## Структура проекта

```
ZeroTrace/
├── App.xaml / App.xaml.cs                 # Точка входа, обработка исключений и Mutex
├── MainWindow.xaml / MainWindow.xaml.cs   # Главное окно со всеми режимами работы
├── CleanupWindow.xaml / .cs               # Диалог очистки остаточных следов
├── ConfirmDialog.xaml / .cs               # Диалоги подтверждения операций
├── Models/                                # Модели данных (приложения, автозагрузка, поиск)
├── Services/                              # Сканеры, криптография, Win32 API и локализация
├── Resources/                             # Стили интерфейса и темы оформления
├── Properties/                            # Метаданные сборки AssemblyInfo
└── tools/                                 # Вспомогательные утилиты генерации ресурсов
```
